# Pixel Lineage Macro

A Windows desktop macro for Pixel Lineage. The setup script creates a local Python virtual environment and installs the dependencies listed in `src/requirements.txt`.

## Run

1. Run `Setup.bat` once.
2. Run `Launch.bat` to start the app.

The app stores its settings in `config.json`. Keep personal settings and Discord webhook credentials in that local file; it is excluded from Git. `config.example.json` shows the webhook fields with empty values.
